# Схемы алгоритмов по СТП

Сначала прочитай `diagram-common`. Схемы строятся генератором `flowchart.py` из `../assets/diagram-tools/`: правила оформления зашиты в код, поэтому рисовать схему в PlantUML, Graphviz или вручную не нужно.

## Что нужно на входе

- Из карты проекта (`project-map.md`): пошаговое описание процесса с условиями ветвления. Нет: сначала `analyze-project-code`.
- Какие процессы показывать: из перечня графического материала в брифе. Пусто: предложи два-три ключевых процесса и получи согласие.
- Файл стандарта, если есть: образец готовой схемы на рисунке 3.33 (стр. 122 СТП БГУИР).

## Правила (итоговые, после всех уточнений руководителя)

**Символы**
1. Только стандартные символы: терминатор со скруглёнными краями («Начало», «Конец»), прямоугольник (процесс), ромб (решение), параллелограмм (ввод и вывод данных). Самодельных фигур нет.
2. Толщина всех линий и контуров одинаковая: 2 пикселя (1,5 пт).
3. Текст: Arial, прямой, без курсива, чёрный, по центру блока.
4. Блоки без заливки, линии чёрные.

**Размеры**
5. Все блоки одной ширины.
6. Все блоки одной высоты, равной высоте самого высокого (обычно это ромб с двумя строками текста).
7. «Начало» и «Конец» вдвое ниже остальных блоков.

**Расположение**
8. «Начало» одно, вверху по центру.
9. «Конец» один, внизу по центру.
10. Основная линия идёт сверху вниз по центральной колонке.
11. Линия входит в блок только сверху. Боковой блок ставится на строку ниже своего ромба: линия идёт из угла ромба вбок, поворачивает вниз и входит в блок сверху.

**Линии**
12. Только горизонтальные и вертикальные отрезки, излом 90°. Наклонных линий нет.
13. Линии могут пересекаться и сливаться. Точка в месте слияния или пересечения не ставится.
14. Соединители (кружки с буквами) не используются. Переход показывается линией.

**Стрелки**
15. На линиях, идущих сверху вниз и слева направо, стрелок нет.
16. При возврате вверх ставится одна стрелка: в точке, где линия возврата входит в основную линию. Развал стрелки 60°.
17. Лишних стрелок нет: одна на каждый возврат. Стрелка в месте входа в блок не ставится.
18. Ветви, которые ведут к завершению, сходятся в одну общую линию без стрелок; в «Конец» входит одна линия сверху. Висящих отрезков и нескольких входов в «Конец» нет.
18а. Допустимый принятый вариант для простой схемы в одну колонку: обходная ветвь «Нет» идёт слева вниз и входит сбоку в основную вертикальную линию перед «Конец»; в точке входа стоит стрелка. Так сделан эталон `flowchart_single_column.py`. В одной схеме используй один способ.

**Ветвления**
19. Из правого угла ромба выходит «Да», из левого «Нет».
20. Если одна из ветвей продолжает основную линию вниз, она выходит из нижнего угла, и подпись («Да» или «Нет») ставится справа от линии под ромбом. Боковая ветвь при этом подчиняется правилу 19: вправо только «Да», влево только «Нет».
21. Подпись ветви стоит над выходящей линией у угла ромба.
22. Боковые ветви соседних ромбов чередуются по сторонам, чтобы блоки и линии не мешали друг другу.
23. Если боковая ветвь упирается в уже стоящий блок или линию, переформулируй условие так, чтобы ветви поменялись сторонами («Отправлялось ранее?» превращается в «Цена ниже прежней?»). Смысл алгоритма сохраняется. О переформулировке сообщи пользователю.

**Текст**
24. В блоке действие глаголом в неопределённой форме: «Выбрать активные товары». В ромбе вопрос: «Остались товары?».
25. Без имён функций и переменных: шаги описываются словами.
26. До 12–14 блоков на схему. Больше: вынеси часть в отдельную схему и сошлись на неё блоком с названием процесса.

## Отменённые решения (не возвращаться)

По ходу работы руководитель менял требования. Эти варианты пробовались и отклонены:
- полное отсутствие стрелок на схеме;
- возвраты через соединители-кружки с буквами, в том числе парные;
- запрет на пересечение и слияние линий;
- вход линии в блок сбоку;
- блоки разной высоты по объёму текста;
- несколько символов «Конец».

Если новый руководитель требует иного, действует его требование: запиши в бриф и измени вызовы генератора.

## Как строить

```bash
cd <папка исходников диаграмм>          # там лежат flowchart.py и render.sh
cp examples/flowchart_loop.py algorithm_<имя>.py
# отредактируй блоки и линии, имя выходного файла в c.save(...)
python3 algorithm_<имя>.py              # получится .svg, печатается размер в пунктах
./render.sh algorithm_<имя>.svg 1.0 9   # PDF, шрифты, кегль на странице
pdftoppm -r 70 -png algorithm_<имя>.pdf просмотр   # открыть и проверить глазами
```

Образцы:
- `examples/flowchart_single_column.py`: одна колонка, две ветви «Нет» обходят блок слева и входят в основную линию со стрелкой. Эта схема была принята как эталон.
- `examples/flowchart_loop.py`: цикл с возвратом, боковые блоки слева и справа, сбор завершающих ветвей в одну линию.
- `examples/flowchart_branches.py`: четыре ветвления подряд с чередованием сторон.

Основное в генераторе:

```python
from flowchart import Chart
c = Chart(ncols=3, col_w=118, col_gap=26, row_gap=9,
          left_margin=28, right_margin=28, font=9, lh=11, uniform=True)
L, C, R = 0, 1, 2
c.block("start", C, 1, "start",    "Начало")          # вид: start | process | decision | data
c.block("d1",    C, 2, "decision", "Остались записи?")
c.block("exit",  L, 3, "process",  "Зафиксировать транзакцию")   # боковой блок на строку ниже ромба
c.block("work",  C, 3, "process",  "Обработать запись")
c.block("end",   C, 4, "start",    "Конец")
c.layout(); c.draw_blocks()
c.line([c.bottom("start"), c.top("d1")])               # основная линия, без стрелки
p = c.no("d1", c.colx[L]); c.line([p, (c.colx[L], p[1]), c.top("exit")])   # «Нет» влево и вход сверху
c.line([...точки...], arrow=True)                      # возврат: стрелка в конце линии
c.save("algorithm_name.svg")
```

- `uniform=True` включает правила 6 и 7.
- `c.yes(...)` рисует подпись «Да» у правого угла, `c.no(...)` подпись «Нет» у левого.
- `c.gapy(r1, r2, доля)` даёт высоту в промежутке между строками: по ней прокладываются горизонтальные участки возвратов.
- `c.gap_after(строка, добавка)` расширяет промежуток, когда в нём проходит несколько линий.
- Генератор не даст провести наклонную линию: упадёт с сообщением «косой отрезок».
- Шрифт ищется через `fc-match Arial`; нет Arial: установи его или задай путь в переменной `FLOWCHART_FONT`.

## Проверка перед вставкой

Открой изображение схемы и пройди по списку:
- [ ] одно «Начало» сверху по центру, один «Конец» снизу по центру;
- [ ] все блоки одной ширины и высоты, терминаторы вдвое ниже;
- [ ] в каждый блок линия входит сверху;
- [ ] «Да» справа, «Нет» слева у всех боковых ветвей;
- [ ] стрелки только на возвратах, по одной;
- [ ] в «Конец» входит одна линия;
- [ ] линии не проходят сквозь блоки и по тексту;
- [ ] текст не вылезает за контур блока;
- [ ] в отчёте только шрифт Arial, кегль на странице не ниже 9 пт;
- [ ] шаги схемы совпадают с описанием процесса в тексте раздела.

Сомневаешься в правиле: посмотри рисунок 3.33 в стандарте или спроси пользователя. Принятую схему занеси в реестр «Не трогать».
