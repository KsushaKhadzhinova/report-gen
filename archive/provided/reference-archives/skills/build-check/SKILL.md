# Проверка сборки PDF

## Что нужно на входе

Из `coursework-brief.md`: папка сборки (где лежат `Makefile` и `note/note.tex`), способ сборки, базовое число Overfull. Нет брифа или поля пусты: спроси «В какой папке лежат Makefile и note/note.tex?» и запиши ответ.

## Запуск

```bash
<папка скила>/scripts/check_build.sh <папка сборки>
```

Ключи: `--max-overfull N` (по умолчанию 0), `--local` (локальный `latexmk` без Docker), `--no-clean` (не сбрасывать кеш).

Последняя строка вывода: `OK pages=N overfull=N warnings=N` или `FAIL: причины`. Код возврата 0 только при `OK`.

## Что проверяется

1. Сборка завершилась без ошибки.
2. `note.pdf` существует, обновился при этой сборке и читается (`pdfinfo` даёт число страниц).
3. В `note/note.log` нет строк, начинающихся с `!`.
4. Нет неразрешённых ссылок и цитат (`Reference ... undefined`, `Citation ... undefined`).
5. Нет ненайденных файлов (рисунков, разделов).
6. Число `Overfull \hbox` не больше допустимого.

## Что нужно знать

- **Кеш сбрасывается намеренно.** В `Makefile` цель зависит только от `note/*.tex`, а `latexmk` сравнивает содержимое файлов. Если заменить картинку или файл в `sections/`, обычный `make all` может не пересобрать документ. Скрипт удаляет `note.fdb_latexmk` и прежние PDF, поэтому сборка всегда полная.
- **В контейнер монтируется только папка `note/`.** Любой файл, который подключается из `.tex`, должен лежать внутри неё.
- **Образ Docker собирается один раз:** `docker build -t neitex:latex .` в папке сборки. Если образа нет, скрипт подскажет команду.
- **Предупреждения шаблона допустимы:** «Unused \captionsetup», «ExtSizes», «cmap fontenc already loaded». Новые предупреждения о шрифтах, переполнениях или ссылках нужно разобрать.
- **Overfull:** строка вылезла за правое поле. Чаще всего это длинный адрес в источниках (ставь `\allowbreak` после точек и косых черт), длинное латинское слово или широкая таблица. Допустимое число увеличивай только с согласия пользователя.

## Если проверка не прошла

1. Прочитай выведенные скриптом строки лога: там номер строки и файл.
2. Исправь причину в исходнике. Не глуши ошибку ключами и не убирай проверку.
3. Запусти снова. Пока проверка не проходит, итерация не считается выполненной и не коммитится.
4. Если причина в окружении (нет Docker, нет образа, нет шрифта), сообщи пользователю точную команду установки.

## После успешной проверки

Сообщи пользователю число страниц и число Overfull. Если число страниц резко изменилось без видимой причины, проверь, не пропал ли раздел.
