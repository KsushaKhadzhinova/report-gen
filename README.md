# report-gen

Генератор пояснительных записок и отчётов по стандарту предприятия СТП БГУИР. Из одного источника собирает три файла: **DOCX**, **LaTeX** и **PDF**.

Программа работает без IDE-ассистентов: запускается из терминала, а текст пишет языковая модель, облачная (по умолчанию, бесплатно) или локальная.

## Возможности

| Возможность | Команда |
|---|---|
| Курсовой проект по СТП: введение, анализ, проектирование, разработка, руководство, заключение | `make`, `write` |
| Отчёт по лабораторной по файлу задания | `lab` |
| Структура по образцу чужого отчёта (берутся только заголовки и объёмы, текст не копируется) | `from-sample` |
| Исправление готового DOCX: поля, шрифт, отступ, интервал, переписывание совпадающих абзацев, разбор замечаний | `fix` |
| Скриншоты: веб-страницы, окна рабочего стола, вывод консоли, диаграммы Graphviz и PlantUML | `shots` |
| Проверка оформления по СТП (ссылки на рисунки и таблицы, подписи, личные местоимения, заглушки) | `lint` |
| Поиск совпадений с эталонными работами по шинглам и автоматическое переписывание | `overlap` |
| Профиль стиля автора по его прошлым работам | `style learn` |
| Инкрементальная сборка: перегенерируются только изменённые разделы | `write`, `make` |

## Быстрый старт

Нужен только Docker.

```bash
git clone https://github.com/KsushaKhadzhinova/report-gen.git
cd report-gen
docker compose build
```

Первый запуск проведёт по настройке: выбор модели, ключ, изучение вашего стиля, проверка окружения.

```bash
./report-gen.sh start        # Linux и macOS
report-gen.cmd start         # Windows
```

Создание и сборка работы:

```bash
./report-gen.sh init projects/kursach --title "Тема работы"
# заполните projects/kursach/meta.yaml и brief.md
./report-gen.sh make projects/kursach --code /code/мой-проект
```

В `projects/kursach/output/` появятся `note.docx`, `tex/note.tex` и `note.pdf`. Скриншоты лежат в `projects/kursach/screenshots/`.

Установка без Docker: `pip install -e ".[capture]"`, затем `report-gen start`. Для PDF понадобятся XeLaTeX и шрифты Times New Roman или Liberation Serif.

## Модели

Модель выбирается по роли задачи, у каждой роли есть резервные модели.

| Роль | Назначение |
|---|---|
| `writer` | основной текст разделов |
| `rewriter` | переписывание совпадающих абзацев |
| `reviewer` | разбор замечаний руководителя |
| `vision` | описание скриншотов |
| `utility` | служебные задачи |

| Провайдер | Описание |
|---|---|
| `cloud` (по умолчанию) | OpenRouter, бесплатные модели. Ключ: <https://openrouter.ai/keys> |
| `local` | Ollama на вашем компьютере |
| `custom` | любой OpenAI-совместимый сервер, адрес в `REPORTGEN_BASE_URL` |

```bash
./report-gen.sh models --check     # какие модели доступны
./report-gen.sh use local          # переключиться на локальные модели
./report-gen.sh use cloud          # вернуться к облачным
```

Для локальных моделей запустите Ollama: `docker compose --profile local up -d ollama`, затем загрузите модель: `docker compose exec ollama ollama pull qwen2.5:7b`.

Списки моделей лежат в `workspace/models.yaml` и правятся без изменения кода. Бесплатные модели в облаке меняются, поэтому для каждой роли заданы запасные варианты.

## Структура работы

```
projects/kursach/
├── meta.yaml          данные титульного листа
├── brief.md           сведения о работе своими словами
├── sources.txt        список источников, по одному в строке
├── screens.yaml       план скриншотов и диаграмм
├── structure.yaml     собственная структура разделов (необязательно)
├── content/           разделы в Markdown, их можно править вручную
├── screenshots/       собранные скриншоты и index.yaml
└── output/            note.docx, tex/note.tex, note.pdf
```

Формат разделов: заголовки `#`, `##`, `###` (нумеруются автоматически), `# ВВЕДЕНИЕ {-}` для ненумерованных, `{app}` для приложений, `![подпись](файл)` для рисунков, строка `Таблица: название` перед таблицей, ссылка на рисунок меткой `{fig:имя}`.

## Лабораторные, образцы, правка готовых работ

```bash
./report-gen.sh init projects/lab3 --type lab
./report-gen.sh lab projects/lab3 --task /code/task.docx
./report-gen.sh from-sample projects/kursach --sample /code/obrazec.docx
./report-gen.sh fix report.docx --remarks remarks.txt --reference workspace/reference
```

## Проверка совпадений

Эталонные работы кладутся в `workspace/reference/`. Абзацы, у которых доля общих пятисловных фрагментов с эталоном выше порога (по умолчанию 25 %), помечаются, а при генерации автоматически переписываются.

```bash
./report-gen.sh overlap projects/kursach/content --reference workspace/reference
```

## Ограничения

- Модели пишут по сведениям из `brief.md` и анализа кода. Факты, цифры и источники нужно проверять: список литературы программа не придумывает и берёт из `sources.txt`.
- Скриншоты окон рабочего стола возможны только при запуске без Docker, на машине с экраном.
- Титульный лист собирается по данным `meta.yaml` и приближён к форме СТП; официальный бланк при необходимости подставляется вручную.
- Автоматические проверки не заменяют просмотр документа перед сдачей.
