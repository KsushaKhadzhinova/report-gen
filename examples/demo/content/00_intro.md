# ОПИСАНИЕ СИСТЕМЫ

## Основные сущности

Система хранит данные о пользователях и заданиях. Перечень сущностей приведён в таблице 1.1.

Таблица: Сущности системы

| Сущность | Назначение |
|---|---|
| Пользователь | Хранит учётные данные |
| Задание | Описывает выдаваемую работу |

Основные возможности системы:

- ведение списка пользователей
- выдача заданий
- формирование отчётов
